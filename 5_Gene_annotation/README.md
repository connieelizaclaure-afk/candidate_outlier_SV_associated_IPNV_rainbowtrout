# Gene Annotation

The workflow focuses on characterizing the biological impact and identifying candidate genes through comparative genomic databases.

## Directory Structure

The module is organized into the following sub-directories:

*   **5.1_Annotation_of_functional_effects_using_snpEff**: Contains the setup and execution of the `snpEff` tool, including custom database building and VCF annotation.
*   **5.2_Functional_annotation_using_Ensembl**: Contains scripts for extracting genomic coordinates and performing gene-level identification using Ensembl databases.
